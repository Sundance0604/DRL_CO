# β 探索尺度告诉我：完成更多优化，不等于学会更好的控制

## 结论

本轮单因素干预**改善了早停与有效优化指标，但没有改善预选 q-active 控制，开发侧利润均值反而下降**。因此不建议马上把该设置扩展为多种子、多工况确认性训练，也不应继续盲目增大 σβ 或 target_kl。

这项实验为“优化机制”和“控制收益”之间的区别提供了直接的小规模训练干预证据。它没有证明增大探索方差普遍有害，也没有证明可分价格或强化学习无效。当前更适合追查 β 策略梯度、整数动作切换边界和长期信用分配，而不是只追求更多 optimizer steps。

## 这次究竟改变了什么

W40/8 指西部多中心、40 个订单、8 辆车。训练 seed 固定 30001，新旧均为结构化 PPO20，8 次 update、每次 4 个完整运营 episode、每个 episode 24 个主动决策期及完整冷却。

唯一预定干预为初始 `log σβ: −1.5 → −0.5`，α 保持 −0.5。从相同初始化重新训练，全部其他可学习初始 tensor 逐项相同，**没有续接旧模型**。实际标准差扩大 e≈2.72 倍、方差扩大 e²≈7.39 倍。价格编码、公开观测、H=1 MILP、物理约束和现金、clip=0.2、learning rate=0.0003、target_kl=0.03、GAE λ=0.95、γ=1、reward divisor=10000 均不变。

旧对照为冻结 `structured_ppo_q_light_v2` 中的 W40/30001/update8。新模型固定取 update8，不按开发利润选 checkpoint。全部 32 次训练场景抽样与旧记录一致；采样 generator31002、minibatch generator31003、数据抽样 random.Random(31004)。独立重建核验共同标准高斯 ε 流，**不强迫实际动作或后续状态相同**，新训练仍是 on-policy。

增大初始探索尺度会同时改变探索、状态访问、优势和后续更新。本轮检验的是这项整体训练设定的效应，不是固定轨迹下高斯 KL 分母的纯因果效应。

训练池有128个生成场景，32个 rollout 实际覆盖28个不同 scenario seed；重复访问不增加独立实例数。两种方法共享这28个实例的同一32日抽样序列，开发评价则使用4个不同的、训练外场景。

## 优化告诉我：原来的尺度确实限制了更新

每个模型计划 8×8=64 次 minibatch 优化。原始 backend 的真实检查处记录联合样本近似 KL，同时保存 old→new 精确高斯 α/β 分解、均值/标准差项、log_std 和触发时参数；未将 update 结束权重当作触发参数。

|指标|原 PPO20|修改 PPO20|
|---|---:|---:|
|早停 update / 8|7|3|
|实际优化 / 64|47|59|
|完成比例|73.44%|92.19%|
|跳过优化|17|5|
|触发时 β/总精确 KL 中位数|79.26%|50.67%|

实际优化增加 **12 次，较原实际执行数增加 25.53%**；完成比例提高 18.75 个百分点。β 的触发时精确 KL 占比下降，但仍有 3 次联合样本近似 KL 超过原 0.03 阈值而早停。

该 β 比例分别来自旧模型 7 个、新模型 3 个真实触发检查，状态、动作与更新位置并不相同，不能说 β 在统一固定状态上的 KL 降低了某个因果百分比。精确 KL 可按 α/β 相加；样本近似分量不可直接相加。未改变联合 log probability 的求和或对 KL 除以维数。

图 01 的下半图显示**每个 update 的最后一次实际检查**近似 KL；图 02 显示同一检查的精确分解。无早停时，最后检查发生于最后一次优化之前，不等于最终网络的 KL。Policy loss、Critic EV/RMSE、逐次均值/尺度变化见 CSV，均是各自 on-policy 数据上的描述性指标，不代表固定状态的预测质量竞赛。

## 控制告诉我：更大的 β 仍未越过本批业务决策边界

动作诊断复用上一轮已查看的 7 个 q-active 和 2 个 q-only 状态，属于机制开发集，不是新确认性测试。其合法 q≥2 证人、原约束摘要和状态哈希保持不变；既有 q-active 标签表示存在当前 H1 macro-action 可行方案，不代表每个 q 方向都能随当前动作自由改变。

旧模型的完整/β=0 结果只读复用；新模型在相同状态运行完整信号及同 α、β=0，共新增 18 次求解。规范化只合并真正状态等价的同质车辆，不把重新编号当业务切换。

|指标|原模型30001|新模型30001|
|---|---:|---:|
|q-active 中 β 归零切换 / 7|0|0|
|q-only 中 β 归零切换 / 2|0|0|
|9 状态、10 个 β 分量的平均绝对值|0.03315|0.06927|
|相同状态间 β 响应 RMS|0.0001354|0.0001683|

响应 RMS 定义为：各 β 维度在九状态中减去该维状态均值后，所有偏差平方的平均再开方。它是归一化动作单位的描述量，不是美元、不作显著性检验。

β 幅度约翻倍，响应 RMS 略增，但绝对状态响应仍很弱。九个状态中新旧完整策略的规范化业务动作也全部相同。**幅度增加没有形成这批状态中的新增控制响应。**

这里的旧模型为固定 seed30001，而上一轮 1/21 的已学切换汇总了三个训练 seed，唯一切换来自30003；不能把本轮0/7写成从上一轮1/7下降。

七个状态均有可行 q≥2 证人，因此“完全没有 q≥2 结构”不能解释整个 active 集。但目前无法区分新 β 方向不对、幅度未达切换阈值、或者对应释放组主要由已有承诺固定。之前人工 β 的切换证明部分状态有控制能力；本轮没有在新 α 下追加人工斜率搜索，不能冒称测出了新模型的切换边界。

## 现金告诉我：机制改善没有转成开发利润

按预登记递增规则，取此前未执行、内容与训练隔离的 W40 seed21024–21027。它们来自既有 CFS 准备池，其原 input hash 核验一致；这是**新的开发评价**，不是新采集的真实日期。没有使用22020–22075各轮已查看的正式测试作调参。

两种冻结 update8 模型均用确定性 tanh(μ)，相同外生场景，24 个主动决策期加全部冷却。未用任何场景利润选择模型或保留子集。

|开发 seed|原利润 USD|新利润 USD|新−原 USD|完成订单：原→新|
|---|---:|---:|---:|---|
|21024|36,726.22|33,697.56|−3,028.66|29→26|
|21025|32,629.76|32,629.76|0.00|26→26|
|21026|48,153.04|48,153.04|0.00|33→33|
|21027|33,281.67|25,091.25|−8,190.42|28→23|
|均值|37,697.67|34,892.90|**−2,804.77**|29→27|

两个场景下降、两个持平，没有正向场景；新均值比原低约 7.44%。在21024和21027，收入分别减少约4,111.86、6,835.54 USD，实际空驶成本分别增加约1,665.59、1,886.90 USD。空驶成本由原账本实际空驶距离×既定2.2单位成本计算，并非 MILP 战略价值项。收入、总成本、完成订单、空驶成本、solver 时间和 episode 时间完整保存在配对 CSV。

这批结果不支持将此设置作为当前利润改善方案，但仅有四个开发场景、一个训练 seed，**没有总体显著性或普遍有害的结论**。两个零值是实际相同利润，不是未运行或缺失值。本轮未运行 Pure MC，不把这些均值与其他场景上的 MC 均值混比。

训练初始 β 的尺度变化最终也会影响 α、Critic 和访问轨迹。不能仅由开发利润下降归因于“确定性 β 太大”；尤其本轮 β 消融只覆盖九个开发状态，而非两策略全部闭环部署时刻。

## 八问的回答

1. **是否减少早停？**是，对这一固定训练 seed，从7/8降至3/8，尚未证明跨 seed 稳定。
2. **有效优化增加多少？**47→59，增加12次，计划64次保持不变；更多优化不自动等于更优策略。
3. **β 联合 KL 贡献是否下降？**触发时精确占比中位数79.26%→50.67%，但新旧触发集合不同，且3次联合近似早停仍存在。
4. **是否更常改变 q-active 业务决策？**没有，旧新均0/7；两 q-only 也均0/2。九状态新旧策略业务动作相同。
5. **状态响应是否更明显？**描述性 RMS 略大，但仍约10⁻⁴，远小于平均幅度0.069；未建立有用控制响应的改善。
6. **开发完整利润是否更高？**没有，平均差−2,804.77 USD，两负两零。只描述本批开发结果，不作显著性检验。
7. **更多步骤但控制不改善，下一步是什么？**研究 β 梯度、可行候选的切换阈值及长期信用分配，分别检查方向、幅度和实际可控支持，不能继续只放大方差/阈值或训练次数。
8. **是否值得多种子确认性训练？**目前不足以把这一设置作为成功候选扩展确认。小规模重复可用于研究机制的种子敏感性，但不同于确认利润优势；本轮不自动追加。

## 下一步仍应轻量，而不是继续扩大这次训练

建议下一次先复用两种模型和原始训练记录做**无新训练的梯度/信用分配诊断**：记录 β actor head 与共享编码器的真实策略梯度、裁剪前后和实际参数位移，区分梯度信号弱与只被联合几何限制。插桩需以独立协议证明不改变原优化轨迹，不能用 Adam 更新范数冒充收益贡献。

另一条小诊断只取先冻结的少量有人工切换证据的状态，固定新 α，沿预设 β 方向作有限幅度扫描，找决策边界，并用完整冷却回报检查越界方向是否有利。状态、方向和扫描上限须先登记，不根据利润搜索赢家。这可以区分学到的方向不对、离阈值远、可用释放组被冻结等机制。

只有这些诊断提供可解释且可重复的信息，再决定改变优势/信用分配、状态—动作匹配，或独立比较联合动作排序。当前既不建议盲目增大 σβ，也不宣称必须放弃资源价格、必须换 RL 算法或已经证明联合动作更优。

## 成本与核验

实际新增数值 **93.891 秒，约1分34秒，978 次求解**：32训练日×24=768、8个旧/新开发运行×24=192、18探针。没有额外 smoke 求解；所有上限内完成。历史实测耗时的保守预算外推为429.52秒，事先通过600秒门；没有结果后追加训练或提高预算。编辑、准备身份核验、独立 QA、绘图和报告另计，不把整项工作说成只花了94秒。

独立 QA 复算新旧64训练日、16次优化、116个真实 KL 检查及实际触发快照；新模型每次更新的网络、Adam、三个 RNG 与保存记录一致，共同 ε 和原场景序列一致。再检查8个开发日的确定性 Actor、完整冷却与账本，及36个探针计划（旧18只读复用、新18实际求解）。共72完整日回放不是72个新训练日，也不是72独立统计样本。

无 MC 访问 guard 通过；公开观测、价格公式、路线/容量/承诺、利润与奖励望远镜求和、终端冷却均核验。五CSV由 bundled NumPy 管线生成并按底层记录逐单元格重算；真实零和不适用分开。四组 SVG 与600dpi PNG；首次利润图发现持平两点互相覆盖，仅作横向显示错位，重新导出、审阅，不改任何利润或统计。没有PDF。

准备阶段曾因把“已冻结的准备池”误当成具有 `final_manifest.json` 的完成实验而失败，输出尚未创建且零求解；随后按该池原 `manifest.json/input_hashes` 验证原场景哈希。未修改历史、未改样本规则或数值数学。最终相关7项非求解单元测试另执行并保存真实XML；2项旧求解测试明确排除，不冒称平台全矩阵。预检不能代替最终QA。全部门通过后才冻结COMPLETED，以 final manifest 为准。

最终实际测试为 **7 passed、0 failed/error/skipped、2 deselected**，3.45秒。四张最新图已实际逐一视觉检查通过；SVG为同源矢量输出并检查XML，不冒称单独渲染审阅。
