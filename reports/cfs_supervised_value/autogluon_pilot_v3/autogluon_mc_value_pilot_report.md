# AutoGluon监督资源价值轻量实验 I

本轮只运行W40/8，监督学习而非强化学习；训练两个AutoGluon，不追加PPO或MC数据生成。标签预检及语义对齐见supervised_data_audit.md。

## 数据、时间与资源语义

使用第六轮精确核算的 16,800 个非终端配对边际记录，80个完整场景：48训练、12验证、20独立监督评价。每标签一个共同未来，无法估计状态内MC标准误。跨场景误差包含条件方差，不把标签当无噪声Bellman真值。

旧标签在释放τ执行自由车辆数量替换；输入使用同一M0自然轨迹较早t公开快照。两世界[t,τ)前缀与现金共同抵消，标签不变。没有使用τ时刻状态作t时刻特征，也没有把表值复制到不同状态。该目标包含共同M0前缀，不是候选动作条件价值；资源替换q与在线释放slot q沿用旧近似映射，不宣称严格等价。

PureMC为冻结的第六轮base_tuq，使用全60构建场景；AG只有48训练/12选择，监督评价20组均未参与三种模型构建。Basic按真实表接口只含τ/h/q；State增至20项公开摘要。需求强度仅来自48训练组，旧bucket/prior及未来信息不入模型。

## 研究判断与限制

加入状态使独立监督RMSE从 1689.09 变为 1677.62 USD；是否下降：True。State相对PureMC的六日平均利润差为 -507.49 USD，正差日数 3/6。预测误差与调度利润分别评价，不能用RMSE改善宣称策略成功。

本轮仅一次轻量AutoGluon配置、单一W40、六个开发日，不代表集成方法性能上限或总体优越。有限配对标签含一次实际未来的噪声；固定共同M0前缀与资源替换不是本次候选动作的后继状态价值。后续状态分布会随新provider改变，监督训练覆盖不到全部在线τ/t/q组合，q=5/7依赖模型泛化。

对于MILP关键区域，本次证据限于实际占用q、闭环决策分叉和独立监督排序，尚未估计每个整数最优边界附近的局部预测误差，不能宣称“关键区域误差已改善”。

若状态模型既改善独立预测又呈现跨开发日较一致现金趋势，可下一步单独预登记更多独立场景确认；若二者方向不一致，应先检查时刻/资源替换近似与决策区域误差。当前数据足以开展这次监督试验，但不支持自动升级Deep Sets、残差模型或更多训练；本轮结束不启动第二轮。

## 部署覆盖与解释限制的补充核验

监督数据中的(t,τ)只有 [[0, 0], [0, 3], [3, 7], [7, 12], [12, 16], [16, 20], [20, 23]] 七类。State实际占用的非终端slot共 767 个，其中 756 个（98.57%）的时刻组合未在训练中出现。这里“未出现”指精确组合，不等于已证明模型不能插值或泛化；但τ/t/延迟特征在训练中存在很强关系，当前监督评价也沿用同样的节点规则，不能由该评价保证任意线上时刻组合的质量。

Basic不输入t，不能把上述组合未出现率直接当作Basic的输入外推率。其实际MILP查询中释放时刻未在训练节点出现的数量为 12416；两AG策略实际占用slot的q均在训练q集合内（占用q越界数均0），但MILP构造时仍查询未训练q=5/7。全查询与实际占用必须分开，完整计数在qa/deployment_support.json。这是结果产生后的描述性覆盖检查，没有重新选择模型。

这个覆盖缺口以及共同M0前缀/资源替换近似，是优先检查的假设，不是本次已识别的因果根因。当前不建议直接升级Deep Sets、残差模型或加长训练。Basic的六日趋势值得在另行预登记的新场景确认；状态价值模型应先检查更充分的(t,τ)训练覆盖和实际关键决策区的误差，再决定扩展。此次不启动下一轮。
