# Data

`sample_data.pkl` is the small, versioned 24-step scenario used by the fixed-scenario reproduction commands. It was created by the original flat module layout, so `drl_co.data_io.load_scenario` maps its historical `ORDER`, `VEHICLE`, and `CITY_GRAPH` pickle class paths to the organized package modules.

New random training and held-out scenarios are generated by `drl_co.simulation.scenarios.generate_scenario`; large generated datasets and run artifacts should not be committed here.
