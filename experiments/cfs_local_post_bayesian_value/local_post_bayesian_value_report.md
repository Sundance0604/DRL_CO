# 第四次数值实验报告：局部动作条件价值与 Hierarchical Bayesian V

## 结论先读

本轮已完成 4 工况 × 16 策略 × 40 配对场景的 **2560 次正式运行**，以及 128 次 pilot、320 次旧 frozen-summary 对照。所有 3008 次政策运行成功；独立物理回放检查 **123657 个逐 t 记录**，12 组历史基线回归和独立重新运行均通过。全套测试 142 项通过（一个 Starlette 依赖弃用警告）。

主要结论是：**MC Table 保持强基线地位，Bayesian 没有稳定领先；更低的预测误差未自动转换成更高的策略利润。** 本轮完整局部方案在同一 held-out 目标上的 Cheb/Spline 点估计 RMSE 均低于旧方案，但 16 个新旧政策配对差区间都跨零，不能宣称局部信息已经显著提高 realized profit，也不能把整体方案差异归因于单个新特征。

本报告只评价这组 CFS 派生仿真、有限车队、固定网络与目标构造。没有 DRL、neural value、MCMC 或 LCB 政策；平台默认算法和前三轮数值源码、冻结模型、既有结果未改。

## 1. 方法与统计口径

### 1.1 这次 V 实际是什么

基础槽目标是在相同未来路径、相同求解预算、相同 commitments 下，新生成的有限自由资源边际：
`Vslot(t,g,q) = average[J_MyopicV0(q) - J_MyopicV0(q-1)]`。
槽资源只改变查询 hub 的当前自由车辆；已经承诺的车辆保留。MC Table 按离散 hub/q、有限时间节点构造，不将不同 q 当作独立场景。

另为候选动作生成 fresh 条件目标 Y，再拟合残差 `R=Y−Vslot(t,g,q)`。局部修正的参数形态为：
`C = intercept + hub effect + q effect + additive feature effects`。
Linear 用线性基，Cheb 用逐特征 Chebyshev 基与 ridge，Spline 用三次基及二阶差分惩罚，Bayes 用同一 12 特征预算的 hierarchical Gaussian residual regression。

Bayesian 在 construction 上最大化 marginal evidence 得到 prior/noise，再由 validation 选择 pooling multiplier，闭式求后验：
`Σ=(XᵀX/σ²+Λ⁻¹)⁻¹; μ=ΣXᵀR/σ²`。
主策略只用 posterior mean。预测方差含 `xᵀΣx+σ²`，不包含 MC 基础表与 empirical-hyperparameter 的不确定性。所有变换和方差缩放均随 JSON 保存，没有抽样型 MCMC。

部署时 q effect 按**构造集固定频率平均**，而非根据最终 slot 选择改变 route 系数。实际 MILP 的 continuation 项严格为：
`Σ_g,q Vslot(g,q)·z(g,q) + Σ_terminal_arc C(context_r)·y_r`。
基础 slot 通过 prefix constraints 累加，固定动作修正只在车辆窗口最终 sink 一次领取；不可控承诺释放不领取修正。没有 route-slot 二元乘积或新非线性项。release≥T 的自由资源价值为零。

### 1.2 动作目标不等于真实联合最优 V

在自然 Myopic 状态的固定投影时刻，按确定 hash 选择可行路线（锚点+贪心 coalition）与可用车辆等待动作。先固定这一局部干预；其他车辆继续承诺或等待，到候选 release 前不进行新分配，但正常处理 booking、expiry 与移动；释放后两世界共同采用 Myopic V0 到 full cooldown。

两条经验未来分别为本场景路径与同 split offset=7 donor 路径，不跨 construction/validation/held-out split。这不是已校准的需求后验。标签因此估计的是**固定干预与期间控制下的资源边际**，不是联合 MILP 最优 post-decision value；中间禁止新分配造成的分布偏移是实质性限制。

route candidate 只有当前可见兼容订单集合，并不绑定最终服务订单子集。真实 served、backlog、联合 post supply 只在 optimize 后审计，绝不反馈到本次价值系数。

### 1.3 独立样本与区间

- formal 的独立样本为 scenario seed（每工况 n=40）；同 seed 的算法使用同一数据 hash。policy seed=0，无 training seed。
- construction 每工况 40 场景，validation 15，held-out value 12。一个场景中的候选、q 和 donor 标签高度相关，表中行数不是独立 n。
- 利润报告 mean、SD、median、t95 CI；方法差用场景配对差。|skew|>1 时另保存固定 10000 次 bootstrap CI。
- value RMSE 为标签级描述指标；额外的 RMSE 对比采用 12 个 scenario cluster 的 bootstrap，不用标签行数伪造样本量。
- 直接比较预先声明，但**未作多重比较校正**；单个跨零/不跨零不能解释为全局算法排名。
- same-q action-spatial 排名可有不同 release 时刻；严格 same-q+same-release 空间排名本轮 CA 仅 3 对、Western 没有对。缺失记为 —，不记 0/100%。
- compression 或 Oracle ratio 只在相应分母差的 t95 下界>0 时给出；它们是描述性比率，不是信息恢复率、等价检验或 DRL 上界。

## 2. 十个研究问题的回答

1. **local action-conditioned context是否比old frozen summary更有信息？** 可合法编码动作release、兼容负载和局部供给提示，表示能力更丰富。但本轮新旧对照混合多个变化，尚不能隔离证明“新增字段本身”的增量价值。
2. **是否改善value prediction？** 新Cheb/Spline在相同held-out Y的8个点估计RMSE均下降，CA幅度较大；cluster诊断支持若干局部方法相对Table的预测改善。该证据属于整体construction+representation+fitting方案。
3. **是否改善realized policy profit？** 相对Zero在若干工况有正配对收益；但相对旧方案16个配对区间均跨零，尚无显著升级证据；也没有优于Table的通用证据。
4. **MC Table为什么仍强？** 有限车辆、离散hub/q和剩余时间信息直接进入slot系数，结构简洁，避开额外action修正的目标偏移与整合误差。6/8均值领先与此解释相容，但不是因果消融证明。
5. **Chebyshev与Spline是否稳定胜负？** 没有。全8个直接政策比较跨零；个别value RMSE差不能转成政策赢家结论。
6. **Bayesian partial pooling是否帮助sparse hub/q？** 收缩机制正确，但稀疏hub收益/误差优势不稳定，W80 Table更好；q标签平衡，不能宣称验证了sparse-q优势。强收缩不等于模型失效，也不等于收益成功。
7. **posterior uncertainty是否校准？** 总体95%约91–94%，但q1在W40/W20明显欠覆盖、高q偏保守；iid Gaussian、EB hyper与base uncertainty未完全覆盖，尚不合格为稳健风险策略证据。
8. **Legacy Fluid是否继续失败？** 是：8个framework×condition的配对gain CI均<0，held-out误差很大。结论只针对当前冻结的Fractional LP Dual Surrogate，不能推广到所有fluid value approximation。
9. **RH4+V是否可替代部分RH8？** W40/W80提供值得复验的描述性证据；CA/W20不稳定，没有通用等价/非劣效结论。compression ratio只是条件比率。
10. **下一步瓶颈在哪里？** 优先target construction与optimization integration，再精化离散state abstraction。保持相同base/labels/fitting只开关局部字段，研究期间控制造成的distribution shift、q-average与slot归属近似、incoming去重及候选释放提示。误差异方差/校准随后处理。现有真实post残差CV证据弱，函数逼近复杂度并非首要已证实瓶颈，暂不依据Oracle gap引入neural/DRL/MCMC。

## 3. Go / No-Go

本轮更接近文档Case C+D：**保留MC Table为主要比较基准，保留Linear/Cheb/Spline/Bayes为可解释对照，下一轮先改实验识别和target/integration。**

不采用“Bayesian明显最好”或“Spline稳定最好”的结论。也不把当前局部方案直接替换平台默认算法。可开展严格单因素信息消融、针对性稀疏hub/q设计、conditional未来与异方差校准；这些是后续研究建议，本轮没有偷偷额外训练或改控制结构。
